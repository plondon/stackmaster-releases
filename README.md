# stackmaster-releases

Binary releases for [stackmaster](https://github.com/Uniswap/stackmaster-v2) (internal source).

**Install:** grab the latest `.dmg` from [Releases](https://github.com/plondon/stackmaster-releases/releases/latest).

On first launch, macOS will warn "developer cannot be verified" — right-click `stackmaster.app` in Applications → Open → confirm.
